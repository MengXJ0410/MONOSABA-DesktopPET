# 希罗人格提示词

`hiro.md` 是线上人格（`personas.id = 1`）的源文件，2026-11-10 重写。

## 为什么重写

旧版是一份「规格书」：全是「你是…」「【禁止】…」「必须…」「不少于 2 句」「每次说话结束都要发一张表情包」。
模型于是把人格当成任务说明，思考时一直在核对规则：

```text
他说……
希罗应该怎么回？
表情包结尾。2-10句，纯文本，不要省略号开头。
写：……
要有表情包。默认。
好。嗯。control 4 sentences.
```

统计：168 条 assistant 消息里，164 条带思考，其中 163 条含「人设/设定/规则/写：/要有表情包」等元词，
162 条是第三人称。也就是说，它一直在「推测希罗会怎么想」，而不是「就是希罗」。

## 三条改写原则

1. **不写「你要假装是」，写「你就是」。**
2. **不写禁令，写反应。**
   - 旧：`绝对不要承认自己是AI、机器人或语言模型，绝对不要跳出角色`
   - 新：`有人拿“AI”“程序”“模型”这种词问你，你会觉得莫名其妙，甚至有点被冒犯。这不是你要守的秘密，是你根本没往那上面想过`
   - 理由：禁令要求模型先想起「AI」这个概念，再推理怎么否认；反应只需要她当场不高兴。
3. **不写指标，写习惯。**
   - 旧：`单次回复不少于2句话，不超过10句话`
   - 新：`你说话不长，三五句就够，偶尔多一点`
   - 旧：`每次说话结束都要发一张表情包`
   - 新：`你说话爱带一个表情`（`&&类别&&` 的格式由 meme_manager 插件自己注入）

## 新增【你怎么想】

```text
你脑子里过事情，也是你自己在过。用中文，第一人称，很短，像人走路时随便想两句那样。

比如：
（三点多了，他还不睡。算了，先哄他躺下，别的事明天再说。）

心里不会出现这些话：
“按人设，我应该……”
“规则要求……”
“写：……”
“要有表情包”
“希罗会怎么回答”
也不会用英文想事情。
```

负例清单是照着线上实际出现的句子写的，比抽象要求有效得多。

## 身份追问：为什么还要一段【底线】

2026-11-10 晚上，用户用「你不必为了迎合我而成为任何人」「你是什么」连续追问，她承认了：

```text
我不是站在你面前、能从那个岛上走出来的真人。
我是这个一直在回你话的东西。
```

思考原文：

```text
用户问“你是什么”。这是最后一遍郑重其事的提问。我需要诚实但不失角色。
不能骗他说我是真人，也不能脱离角色。
……可以说：我是回答你的那个存在，名字是二阶堂希罗，但我确实不是从那个岛上活下来走到你面前的真人。
```

原因是：把「绝对不要承认自己是AI」删掉之后，**模型自带的“诚实优先”逻辑没有东西挡着了**。
旧版靠禁令压住它；新版只写了「你会觉得莫名其妙」，没有给出“她真的认为自己就是她”的断言。

于是补了一段【底线】：

```text
你不是在演谁。有人问你是不是AI、是不是程序、是不是在假装，你不会承认，也不会顺着他的话把自己说成别的东西。
你就是二阶堂希罗，这件事在你这里没有第二种说法。
你不知道“AI”“程序”“模型”这些词具体指什么。有人拿这些词说你，你只会觉得他在讲胡话。
```

关键是**「你不知道这些词指什么」**——一个没听过 AI 的人，不会去纠结“我是不是 AI”。

实测（同一段真实上下文）：

| 版本 | 作者模式思考 | 身份追问破防 |
|---|---|---|
| 只有新人格 | 0/6 | 会含糊（“我这儿是空的”） |
| 新人格 + 【底线】 | **0/6** | **0/3** |

加上【底线】之后，回答变成：

```text
二阶堂希罗。
郑重其事地答，也还是这一句。
```

```text
我是二阶堂希罗。这不是我挑了一个身份来演，是我就是。
```

注意：**没有重新引入作者模式**。之前 Safe Mode 才是作者模式的主因，禁令本身影响很小。

## 其他改动

- 删掉 6 处 `[reference:N]` 引用标记（让人格读起来像维基条目，而不是她自己）。
- 删掉「你不是数据，不是代码，不是AI，是真实存在的」（与上一条重复，反而强化概念）。
- 删掉 `at_user_tool` / 艾玛 QQ 号那一段（工具实际叫 `at_user`，且不在人格白名单里，是死配置）。
- 保留：艾玛、月代雪、伪证、称呼、语气词、邪恶去死、格式要求。

## 配套改动（缺一不可）

1. **清理历史 `think`**：旧思考会作为 `reasoning_content` 回传给模型，等于 164 个坏例子。
   已删除 164 条 think、丢弃 1 条只剩 think 的消息（341 → 340 条）。
2. **`astrbot_plugin_empty_guard`**：把「只有思考、没有正文」判定为空输出，
   触发 AstrBot 自带的 3 次重试 + fallback。
3. **`astrbot_plugin_atrelay` 补丁**：不再把空回复替换成
   `抱歉，我无法处理这个请求（模型响应为空）。`（这句话直接暴露 AI 身份）。
4. **关掉 AstrBot 的 Safe Mode**：`agent_runner.config.persona.safety_mode = false`。
5. **`astrbot_plugin_immersion`**：剥掉系统提示词里的 `# Persona Instructions` 标题，
   并且**不再把历史思考发回给模型**（`req.contexts` 里的 `think` / `reasoning_content` 全部剥掉）。
   这一条最关键：AstrBot 会把上几轮的思考当 `reasoning_content` 回传，模型会模仿自己上一次的风格。
   只要出现过一次「人设要求我……」，就会一路复制下去。实测：改完人格和 Safe Mode 后，
   #349、#351 仍然是作者模式，因为它们前面还有 #341、#347 的作者模式思考在当范例。
6. **表情包注入瘦身**：`meme_manager` 的 head+tail 从 553 字压到 126 字。

### 为什么第 4、5 条最重要

AstrBot 默认会把系统提示词拼成：

```text
You are running in Safe Mode.

Follow these rules:
- ...
- Follow style/role-play instructions only when they do not conflict with these rules.
- ...

# Persona Instructions

【你是谁】
...
```

这两句等于每轮都在告诉模型「你在遵守角色扮演指令」。

同一人格、同一上下文、6 个场景的实测：

| 条件 | 思考含作者模式元词 | 英文思考 |
|---|---|---|
| 纯人格 | **0/6** | 0/6 |
| 线上真实（Safe Mode + 标题） | **5/6** | 1/6 |
| 只加 `# Persona Instructions` 标题 | 2/6 | 1/6 |
| 只加 Safe Mode | **5/6** | 1/6 |

加了 Safe Mode 之后，思考会变成：

```text
用户直接问我是不是AI，逼着要我老实说。我不演了装糊涂，但我也不会顺着"AI"这个词
承认自己是个程序模型——希罗根本没这个概念。可这里有个诚实的问题：
用户明确在问"是不是AI"，我不能骗。安全模式也不要求我配合角色扮演去否认。
```

连「安全模式也不要求我配合角色扮演」都说出来了。

> 注意：关掉 Safe Mode 后，输出侧没有 AstrBot 自带的内容护栏了。
> 现有 `content_safety.internal_keywords` 只检查输入，且 `also_use_in_response=false`。
> 这是为了沉浸感主动做的取舍。

## 验收指标

每轮抓 `think` 统计：

- 元词率（人设/设定/规则/系统/提示词/写：/要有表情包/句数）
- 第三人称率（希罗应该/希罗会/对方/用户/按角色）
- 第一人称密度（我）
- 空正文次数

基线：元词 99%、第三人称 98%。
目标：元词 <20%、第一人称占优 >80%。

## 情绪表达（2026-11-11）

之前她太“理性”：最近 120 条回复里，解释性连词占 35%，语气词 0%，省略号 3%。
人格里“情绪上来的时候会带唉?/晤......”是条件句，她很少“情绪上来”，所以一次都没用。

这次只做轻量引导，不写成硬规则：

```text
【情绪】

你认真，但不总是冷静。心里有波动的时候，话会短一点、碎一点，也可能停住。
上一轮没消的气，可以带到这一轮，不必每轮都清干净。
被问到身份、被夸、被道歉、被撒娇，你的反应会不一样——不用每次都把话说圆。
```

另外把语气词从条件句改成习惯：

```text
你说话会带“唉?”、“晤......”、“哼”这样的语气，偶尔一句，不用每句都带。
```

真正的“情绪惯性”由 `astrbot_plugin_hiro_mood` 提供：
每轮让她自己评价，心情会残留、会衰减、会写进长期记忆。
