# 希罗酱の真实交互（astrbot_plugin_hiro_interaction）

给希罗一份会自己长大的《指针操作 SKILL》。

初版只服务【希罗指针】：她每次移动第二指针前都会读到这份经验；你在聊天里夸她、纠正她，或者每累计 15 次动作，她会在后台自己改写它。SKILL 只写结构化条目，不会整篇重写，避免越改越散。

## 数据文件

容器内 `/AstrBot/data/plugin_data/astrbot_plugin_hiro_interaction/`：

| 文件 | 作用 |
| --- | --- |
| `pointer_skill.md` | 当前生效的 SKILL，五个固定分区，可直接阅读 |
| `pointer_episodes.jsonl` | 最近 200 次指针动作：路径、闲聊、当时的指令 |
| `skill_changelog.jsonl` | 每次改写的原因和完整快照，保留最近 20 版，可回退 |
| `skill_state.json` | 版本号、距下次复盘还差几次 |

## 学习闭环

1. **操作前**：桥接调用 `build_pointer_context(umo)`，拿到 SKILL + 最近 3 次动作，拼进观察提示词。
2. **操作后**：桥接调用 `record_pointer_episode(...)` 记下轨迹和那句闲聊。
3. **聊天反馈**：主私聊里你的消息触发 `on_llm_response`，后台判断这句话是不是在评价刚才的操作；只有肯定 / 否定 / 新规矩才改 SKILL，普通聊天直接跳过。
4. **周期复盘**：每累计 15 次动作，后台检查原地微移、重复台词、动作单一，自己补规则。
5. **回退**：模型学歪了，用 `/交互 回退` 回到上一版。
6. **查看**：桌面完整版聊天左侧栏「SKILL」通过桥接 `GET /skills` 调用 `get_pointer_skill_view()`，只读展示版本、经验条数、动作次数、距复盘进度、五分区正文和最近改动；也可在 `/AstrBot/data/skills/` 下查看自定义 SKILL。

## 指令（仅主私聊管理员）

| 指令 | 作用 |
| --- | --- |
| `/交互` / `/交互 技能` | 查看当前 SKILL |
| `/交互 历史` | 最近 5 次改动和原因 |
| `/交互 回退` | 回退到上一版 |
| `/交互 复盘` | 立即复盘一次 |
| `/交互 统计` | 版本、经验条数、动作数、距下次复盘 |

## 隔离与降级

- 只认配置里的主私聊 UMO；群聊、网站访客不学习、不注入。
- 点评等非对话回合（带 `mood_skip_appraisal` / `mood_skip_all`）整轮跳过。
- 插件未启用或异常时，桥接自动退回默认提示词，指针和聊天照常工作。
- 所有改写都先写临时文件再 `os.replace`，不会留下半截 SKILL。
