SKILL 是完整版聊天窗口左侧栏里的一个只读查看入口。它回答两个问题：

1. **希罗现在会怎么用第二指针？** —— 她自己整理的《指针操作 SKILL》长什么样、改过几次、还差多少次动作复盘。
2. **服务器上还装了哪些 SKILL？** —— 比如《二阶堂希罗 · 详细背景设定》，以及以后放进 `/AstrBot/data/skills/` 的自定义技能。

它不是编辑器，也不会替她改经验。所有学习仍然在后台发生，面板只负责让你看见。

## 入口与布局

完整版聊天窗口左侧导航：

```text
聊天
心情
SKILL   ← 新增
设置
```

点击「SKILL」后，右侧栏从「心情 / 设置」切换成 SKILL 查看模块：

- **宽窗**：内嵌在右侧，和心情面板同宽；
- **中 / 窄窗**：覆盖式抽屉，点遮罩、按 `Esc` 或再点一次「SKILL」收起；
- 顶部有更新时间、刷新按钮和收起按钮。

顶部是一个选择器，列出当前可看的 SKILL：

- **希罗指针操作 SKILL**（默认选中，带版本角标，如 `v1`）；
- `/AstrBot/data/skills/` 下的自定义 SKILL，例如《二阶堂希罗 · 详细背景设定》。

AstrBot 自带的 `documents`、`pdf`、`spreadsheets`、`skill-creator` 是通用办公技能，不会出现在这里。

## 指针 SKILL：鼠标熟练度

选中「希罗指针操作 SKILL」后，面板从上到下是：

### 1. 熟练度概览

| 指标 | 含义 |
| --- | --- |
| 版本 | `vN`，每次反馈学习 / 周期复盘 / 回退都会 +1 |
| 条经验 | 五个分区里当前有多少条可执行经验 |
| 次动作 | 累计记录了多少次真实指针动作 |
| 距复盘 | 还差多少次动作触发下一次自我复盘（默认 15 次一轮） |

下面有一条进度条，表示距离下次复盘的进度。动作记录只统计真正下发到桌面的指针动作，不包括模型「想了但选择不动」的轮次。

### 2. 五个分区正文

指针 SKILL 固定五个分区，顺序不会变：

1. **落点与避让直觉**：指针该停在哪、避开什么；
2. **连续轨迹技巧**：画圈、晃动、连续指两处时怎么给 `steps`；
3. **常见场景经验**：游戏 / 视频 / 代码 / 桌面闲置；
4. **闲聊搭话风格**：移动时那句闲聊怎么说；
5. **高优纠错与禁忌**：你明确夸过或批评过的点，权重最高。

这些条目是她自己写的，不是预设提示词。每次观察前桥接会把当前 SKILL 和最近 3 次落点带给她，所以她会记得上次停在哪、哪些位置被夸过或批评过。

### 3. 最近改动

底部展示 `skill_changelog.jsonl` 最近 5 条改写记录：

```text
v2  聊天反馈  11-21 20:47  确认画圈轨迹圆、收尾停在旁边不遮挡的做法值得保持
v1  初始      11-21 20:48  初始 SKILL
```

来源标签：

| 标签 | 触发方式 |
| --- | --- |
| `聊天反馈` | 主私聊里你夸她 / 纠正她 / 立新规矩，她判断这句话在评价刚才的指针操作 |
| `周期复盘` | 每累计 15 次动作，她后台检查原地微移、重复台词、动作单一 |
| `回退` | 你发 `/交互 回退`，恢复上一版 |
| `初始` | 插件第一次启动时写入的种子经验 |

## 自定义 SKILL：背景设定等

选择器里的自定义项来自服务器：

```text
/AstrBot/data/skills/
├─ SKILL/
│  └─ SKILL.md        # 二阶堂希罗 · 详细背景设定
└─ <你的技能>/
   └─ SKILL.md
```

渲染规则：

- 一级标题 `# ...` 作为技能名称（没有就用目录名）；
- 二级标题 `## ...` 分成阅读卡片；
- `- ` 开头的行渲染成条目；
- 自动去掉 `[reference:nn]` 引用角标和 `**` 粗体标记；
- 如果 `SKILL.md` 带 YAML frontmatter，`description` 会显示在标题下方。

以《二阶堂希罗 · 详细背景设定》为例，面板会按「基础资料 / 官方设定的兴趣与特技 / 游戏世界观 / 核心创伤 / 与艾玛的关系演变 / 性格细节 / Happy End 后的日常」分节展示，不会把整篇 4KB 文本糊成一团。

## 数据链路

```text
桌面聊天渲染层
  → window.petApi.chatSkills()
  → 主进程 GET /skills
  → astrbot_plugin_desktoppet_bridge
      ├─ interaction.get_pointer_skill_view()   # 指针 SKILL 统计 / 五分区 / 改动
      └─ 扫描 /AstrBot/data/skills/*/SKILL.md   # 自定义 SKILL
```

- 指针部分由《真实交互》插件提供，桥接不直接读 `pointer_skill.md`，避免文件字段变化时桌面跟着坏。
- 自定义部分由桥接扫描目录，过滤 AstrBot 自带办公技能。
- 接口只读，不会修改任何 SKILL，也不会触发模型调用。

## 只读边界

- 面板没有编辑、保存、回退按钮；改歪了仍然用 `/交互 回退`。
- 刷新只是重新拉一次 `/skills`，不会加速她的学习。
- 群聊、网站访客不学习、不注入指针 SKILL；这个面板也只显示主私聊这一份。
- 插件缺失或异常时，桥接返回不可用状态，面板显示错误；聊天和指针不受影响。

## 常见问题

**Q：为什么指针 SKILL 只有 17 条经验？**

那是种子经验。她需要真实移动指针、收到你的反馈，才会继续长。刚装好、还没开指针时看到 17 条是正常的。

**Q：为什么「次动作」一直是 0？**

指针总开关没开，或者开了但画面一直没明显变化（省 token 设计，不调用模型）。先确认面板「真实交互 → 希罗指针」是开的。

**Q：自定义 SKILL 放进去了但没出现？**

确认目录结构是 `/AstrBot/data/skills/<目录名>/SKILL.md`，文件名必须是大写 `SKILL.md`；改完在面板点刷新。桥接只认大写 `SKILL.md`，小写 `skill.md` 不会自动改名，也不会出现在列表里。

**Q：能看到 AstrBot 自带的 pdf / excel 技能吗？**

不会。那些是通用办公技能，和希罗无关，面板刻意过滤掉了。

**Q：在面板里能改她的经验吗？**

不能。这是只读查看；需要纠正她时，直接在聊天里说「别盖字幕」「这个圈画歪了」，或者用 `/交互 回退`。
