# Wiki 发布稿

这四篇是给网站知识库「Live2D桌宠」分类准备的 Markdown，按「我写好、你发布」的方式交付。

| 文件 | 对应文章 | 处理方式 |
| --- | --- | --- |
| `wiki-整体设计架构.md` | 整体设计架构 | 覆盖现有 0 字节占位文章的正文 |
| `wiki-更新日志.md` | 更新日志 | 覆盖现有 0 字节占位文章的正文 |
| `wiki-仿QQ聊天终端.md` | 仿QQ聊天终端 | 在「Live2D桌宠」下新建文章 |
| `wiki-希罗指针.md` | 希罗指针 | 在「Live2D桌宠」下新建文章 |

## 复制方式

每篇文件的结构：

```markdown
---
title: ...
summary: ...
tags: [...]
order: ...
---

> 发布信息（复制到编辑器对应输入框，正文从分隔线后开始）
> ...

---

正文……
```

1. 把 frontmatter 里的 `title` / `summary` / `tags` 填进网站编辑器的标题、摘要、标签栏；
2. 正文从「发布信息」引用块下方的那条 `---` 之后开始复制（包含所有标题、表格、代码块）；
3. 「整体设计架构」「更新日志」直接覆盖占位文章的正文后保存；「仿QQ聊天终端」用「新建文章」再粘贴。

## 更新约定

- 桌面端版本变化时同步更新 `wiki-更新日志.md`，再覆盖到网站。
- 桥接插件版本在「整体设计架构」开头的版本行里维护。
- 文章里的数据（缓存上限、轮询间隔、截图尺寸）与仓库 `架构设计.md` 保持一致；改代码时两边一起改。
